            Developer quickstart

            Run the full stack locally

            FastAPI on 127.0.0.1:8000 and the Streamlit control tower on 127.0.0.1:8501, bound to loopback only. A random signing key is generated on first run.

            git clone https://github.com/samuelhtampubolon/autonomous-b2b-procurement-agent.git
cd autonomous-b2b-procurement-agent
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt

python run_local.py --check   # DB, seed, probes, headers, audit chain
python run_local.py           # API :8000 + Control Tower :8501
pytest -q                     # full test suite
