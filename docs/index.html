Run Locally with 1 Command

Deterministic startup with automated port conflict resolution, SQLite auto-seeding, and cross-platform compatibility across Windows, macOS, and Linux.

git clone https://github.com/samuelhtampubolon/autonomous-b2b-procurement-agent.git
cd autonomous-b2b-procurement-agent

# 2. Install dependencies
pip install -r requirements.txt

# 3. Deterministic preflight check (Seeds 50 invoices & validates healthz)
